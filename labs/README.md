# Labs

Each workshop this semester adds a lab folder here. Pull the newest ones into your fork with:
```
git pull upstream main
```

> ⚠️ **Educational use only.** Labs may include intentionally vulnerable systems. Run them
> only on an isolated lab network - never the public internet. See [../DISCLAIMER.md](../DISCLAIMER.md).

## How a lab works
1. Pull the lab folder from upstream.
2. Build (or connect to) the environment using the lab's own guide.
3. Do the work, then **document it in your own portfolio repo** - findings, commands,
   screenshots, what you learned. (Keep solutions and flags out of any public repo.)
4. Add or update the project entry on your portfolio so the lab becomes a portfolio piece.

*(Lab folders will appear here as the semester's workshops are released.)*
