# Members

This folder is the S617 member directory. Each file here is one person's entry -
their name, focus, and a link to their portfolio.

## Add yourself (this is your first pull request)

1. Copy `_TEMPLATE.md` to a new file named after you:
   `members/firstname-lastname.md` (or your handle: `members/username.md`).
2. Fill it in. Link to your **portfolio repo** for now; swap in your live
   **GitHub Pages URL** once your site is up.
3. Commit it to your fork, push, and open a pull request back to this repo.

> **You only ever add your own file - never edit someone else's, and there is no
> shared list to update.** That's deliberate: it means your pull request can't
> collide with a classmate's. GitHub lists everyone in this folder automatically.

See `EXAMPLE-alex-rivera.md` for a filled-in example, and
[docs/03-add-your-link.md](../docs/03-add-your-link.md) for the full walkthrough.
