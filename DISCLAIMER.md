# ⚠️ Disclaimer - Educational Use Only

This repository and all of its materials - labs, guides, configurations, virtual
machines, and infrastructure code - are provided **solely for educational purposes**
as part of cybersecurity coursework at Hudson County Community College (HCCC).

## Authorized use only

The techniques and tools demonstrated here are intended to be used **only** against
systems that you own or have explicit, written authorization to test - such as the
isolated lab environments provided for this course. **Never** use them against any
system, network, account, or device that you do not own or lack permission to assess.

## Unauthorized access is illegal

Unauthorized access to computer systems is a crime. It may violate federal, state,
and local law - including the U.S. Computer Fraud and Abuse Act (CFAA) - as well as
HCCC's acceptable-use policy. **You alone are responsible for your actions.**

## Intentionally vulnerable systems

Some machines and configurations in this repository are **deliberately insecure** so
they can be practiced against. Run them **only** inside an isolated lab network.
**Never** expose them to the public internet or connect them to a production or
personal network.

arising from the use of these materials.
